## LockBrowser
browser alternative untuk membuat guest browser dan dapat memiliki keamanan password agar profil tidak dapat di buka oleh orang lain. 

### Install

```bash
git clone https://github.com/yohanesokta/LockBrowser.git
cd LockBrowser

python -m venv venv
source ./venv/bin/activate
pip install -r requerements.txt
python main.py
```
